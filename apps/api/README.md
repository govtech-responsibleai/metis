# metis-api

> **Beta: experimental.** The HTTP API is not on the supported beta path. It can change between
> betas, and it can break. It has routes for the wizard Interview, the graders, and the models.
> It has no routes for the engine. See the Feature status table in the
> [root README](../../README.md#feature-status).

metis-api is a thin HTTP layer over the Interview interface of the wizard. It holds no state. For
instructions on how to work on it, read [AGENTS.md](AGENTS.md).
